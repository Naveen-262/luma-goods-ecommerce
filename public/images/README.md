# Local product images

The product photos in `products/` are stored locally so the storefront does
not depend on an image CDN at runtime. They were downloaded from Unsplash
image URLs for this demo and are used under the [Unsplash License](https://unsplash.com/license).

The source image IDs are:

- `photo-1505740420928-5e560c06d30e` — wireless headphones
- `photo-1523275335684-37898b6baf30` — smart watch
- `photo-1542291026-7eec264c27ff` — running shoes
- `photo-1553062407-98eeb64c6a62` — travel backpack
- `photo-1608043152269-423dbba4e7e1` — Bluetooth speaker
- `photo-1521572163474-6864f9cf17ab` — classic T-shirt

The second product variants use additional Unsplash photos of the same
product categories. Replace these files only with assets you are licensed to
use if this project is published commercially.
